Частые вопросы

Коротко о главном.

Лаунчер действительно бесплатный?

Да. Сам лаунчер бесплатный, без рекламы и скрытых платежей. Игра Minecraft покупается отдельно у Mojang.

Нужна ли лицензия Minecraft?

Для игры на любых серверах нужен лицензионный аккаунт: войди через Microsoft. Офлайн-ник подходит только для одиночной игры и локальных серверов.

Нужно ли ставить Java?

Нет. Лаунчер сам скачивает подходящую версию Java для выбранной версии игры.

Откуда берутся моды?

Из официальных каталогов Modrinth и CurseForge. Лаунчер ищет только то, что подходит под твою версию игры и загрузчик.

Работает ли лаунчер без VPN?

Да. Для Fabric и Quilt предусмотрено зеркало, поэтому установка проходит, даже если официальный сайт загрузчика недоступен.
